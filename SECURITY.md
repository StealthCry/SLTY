# Security Policy

## Supported baseline

Security reports should target the latest code on the `main` branch.

## Reporting a vulnerability

Please do not publish credentials, exploit details, or an unpatched vulnerability in a public issue.

If GitHub's private vulnerability reporting is enabled for this repository, use **Security → Advisories → Report a vulnerability** to send a private report.

If that option is unavailable, contact the repository owner privately through the GitHub profile: https://github.com/StealthCry

Include a concise description, potential impact, reproduction steps, and any suggested mitigation. Do not include real user data or active secrets in the report.

## Scope

This is a personal game project. No formal bug bounty or guaranteed response-time commitment is offered.
