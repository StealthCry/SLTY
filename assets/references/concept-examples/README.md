# Temporary visual concept examples

The WebP images in this directory are temporary visual references illustrating the desired direction for the in-game weapon and first-person hands.

They are **not final production assets**, not approved game-ready models, and should not be imported into the game as finished content. Use them only as visual inspiration when designing or commissioning the final weapon, hands, materials, rig, and animations.

Before using any third-party source material in a distributable build, verify its provenance and license. Record source and usage rights when known.
